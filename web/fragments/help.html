Start here

  1. Upload PDF, HTML, DOCX, XLSX, PPTX, JPEG, PNG, WebP, or another readable UTF-8 text file from Overview or Documents.
  2. Wait until each document shows Ready.
  3. Use Ask to get an answer that combines evidence and includes citations.
  4. Use Chat for a private follow-up conversation that remains grounded in document evidence.
  5. Use Find Sources to locate documents or matching excerpts without generating an answer.

Prepare your documents

Allowed files

  • Documents: PDF (.pdf), HTML (.html or .htm), and Word (.docx).
  • Spreadsheets: Excel (.xlsx).
  • Presentations: PowerPoint (.pptx).
  • Images: PNG (.png), JPEG (.jpg or .jpeg), and WebP (.webp).
  • Other text files: Files with another extension, or no extension, are accepted when they contain valid, nonempty UTF-8 text.

Files that cannot be read as a known format or as plain text are rejected.

CiteLoom indexes the saved results of Excel formulas, not the formulas themselves. Recalculate and save a workbook before uploading it.

PowerPoint slide text, tables, pictures, speaker notes, and comments can be indexed.

  • A document must be Ready before it can appear in Ask, Chat, or Find Sources.
  • If a document shows Reindex required, process it again before searching it with the current embedding model.
  • Use tags to create reusable groups of related documents.
  • Clear headings and selectable text help CiteLoom create useful section names and excerpts.

Manage your library

Use Documents to search, filter, sort, tag, inspect, reindex, and delete saved documents.

  • Collections include all documents, uploads, untagged documents, and each saved tag.
  • Select documents and choose Add to question to carry a focused file scope into Ask or Chat.
  • Open a document to inspect its ingestion stages, indexed text, tables, images, source file, and processing errors.
  • The uploader or an administrator can pause and resume eligible PDF ingestion, cancel active ingestion, and retry failed work.
  • Reindexing builds a replacement while the current ready version remains searchable.
  • Version history lets you open the saved source and compare added, modified, and removed evidence.
  • Deleting a document requires confirmation and does not rewrite evidence already retained by saved Ask or Chat answers.

Administrators choose Standard or VLM PDF processing under Settings → Docling → PDF processing. Standard uses Docling's layout, OCR, and table models. VLM sends each rendered PDF page to the selected visual model.

Ask a question

Use a focused question when you want CiteLoom to combine evidence into an answer.

Good examples

  • Summarize the main conclusions and supporting evidence in these documents.
  • Which clauses describe termination, notice, and each party's obligations?
  • Compare the diagnoses, treatments, and follow-up recommendations in these veterinary records.
  • What findings are supported by tables or test results on pages 10 through 20?

For a complete answer, ask a complete question instead of entering one broad term.

Use Find Sources first for queries such as termination, arthritis, or data retention.

How much document text CiteLoom checks

Administrators can change Matching sections reviewed and Sections available for answers on the Search size screen under Search and answers in Settings.

Matching sections reviewed is the unique candidate budget before reranking. Lower values can miss relevant evidence, while higher values search more broadly but require more search and ranking work.

Sections available for answers is the post-rerank ceiling sent to the answer model. Lower values can omit needed evidence, while higher values increase model input, response time, and distraction risk. CiteLoom may use fewer sections when the remaining matches are substantially weaker.

Matching sections reviewed must be equal to or greater than Sections available for answers.

CiteLoom may use fewer sections when fewer useful matches exist or the selected model cannot accept all of them.

How CiteLoom finds matching sections

Administrators can select Keyword, Semantic, or Hybrid under Settings → Search and answers → Search matching.

Keyword finds exact words and phrases through BM25 and does not call the embedding model for the document query.

Semantic searches by meaning and embeds the document query.

Hybrid is the default and combines Keyword and Semantic results.

An enabled search-ranking model can reorder candidates from any of the three methods.

Chat with documents

Use Chat when later questions should build on a saved document-grounded conversation.

  • Each chat is private to its creator in the current workspace.
  • CiteLoom stores every user message and completed assistant response.
  • Long chats remain focused on earlier messages that matter to the current question.
  • Earlier messages help CiteLoom understand the conversation. Every factual response still requires source material from the documents and citations.
  • If a library document is deleted or replaced, existing chat messages and their retained citation evidence remain unchanged.
  • Deleting the chat permanently removes its messages and saved citation records.

Administrators can configure Chat separately from Ask and the Indexing model in Settings.

Saved research

Ask saves each completed question and answer in a research thread.

  • Create a new thread when you want a separate research history.
  • Opening an earlier turn reads the saved answer, citations, evidence, settings, and retrieval trace without running the question again.
  • Export a thread as Markdown for reading or JSON for structured analysis.
  • Use the answer controls to rate retrieval relevance, answer usefulness, and citation correctness.
  • Deleting a thread permanently removes its saved turns and citation records after confirmation.

Find sources

Use Find Sources to search without generating an answer.

  • Search termination notice to find agreement sections about notice before an agreement ends.
  • Search arthritis with Include semantic matches enabled to find excerpts that may discuss joint disease or pain management.
  • Search follow-up bloodwork to prioritize veterinary records discussing ongoing monitoring.
  • Leave Include semantic matches disabled when only exact terms matter.

Keyword match means a document section contains words from your search.

Semantic match means a document section appears related in meaning even if it does not contain those words.

Find Sources result counts

Matching sections reviewed is the most document sections CiteLoom reviews for each Ask, Chat, or semantic Find Sources request.

Higher values search more material but take longer, and CiteLoom does not silently lower the value you set.

Documents shown in Find Sources controls how many documents appear in the Keyword matches list and the Semantic matches list.

Keyword matches use the number on each page, so later matches remain available on additional pages.

Semantic matches show up to that many documents.

Excerpts shown per document controls how many matching excerpts appear inside each document result.

The two display settings do not change how many document sections CiteLoom searches.

Administrators can change these values in Settings → Search and answers.

Minimum score for Find Sources

Find Sources does not show a semantic match when its search ranking score is below this value.

A higher value shows fewer semantic matches, while a lower value shows more.

The default is 0.9, but search ranking models use different scoring scales.

A score of 0.9 does not mean 90 percent confidence, and the same value can behave differently with another search ranking model.

This setting affects Find Sources only and does not remove evidence from Ask.

Administrators can change it in Settings → Application Features → Search ranking → Show advanced settings.

Choose a search scope

  • Choose All ready documents to search everything that is available.
  • To search specific files, select them in Documents and choose Add to question.
  • Choose Tags to search saved groups such as legal, veterinary, or personal documents.
  • When you choose several tags, CiteLoom searches documents that have any selected tag.
  • Clear selected documents before returning to All ready documents or Tags.

Use dictation

When voice input is enabled, you can dictate a question while using Ask.

  • Hold Option on Mac or Alt on Windows and Linux to record. Release the key to stop and transcribe the recording.
  • You can also use the microphone button to start and stop recording.
  • Choose Cancel to discard a recording without changing the question draft.
  • CiteLoom inserts the transcript at your cursor. You can edit it before submitting the question.
  • Press Command or Control + Enter after reviewing the transcript to submit the question.

CiteLoom sends recorded audio to the configured transcription provider and discards it after transcription or cancellation.

If transcription fails, choose Retry when available to reuse the recording. Otherwise, record the question again.

Listen to answers

When spoken answers are enabled, Ask can read the displayed answer and Chat can read any completed assistant answer in the conversation.

  • Choose the speaker control to prepare and play the answer with the configured speech provider.
  • Use the audio controls to pause, resume, or replay prepared audio.
  • When Preload answer audio is enabled, CiteLoom prepares audio in the background after a completed answer is loaded or published.
  • Changing the answer, thread, or conversation discards the prepared browser audio for the previous answer.

Administrators configure the speech provider, model, voice, speed, preloading, and timeout in Settings.

Understand sources and citations

An inline citation such as [1] links an answer claim to its supporting source.

Retrieved source material shows the document sections CiteLoom considered while preparing the answer.

A document section can be relevant to the question without supporting a claim in the final answer, so not every section becomes a citation.

Find Sources results are search results, not citations.

Improve your results

  • Name the subject, comparison, jurisdiction, date range, or document type that matters.
  • Choose the narrowest scope that still contains the necessary evidence.
  • Use Find Sources to see which terms the documents use before asking a question.
  • Select useful discovery results and then write a complete question about them.
  • Rephrase a question when the indexed documents use different terminology.

Search text formats

Vector dimensions and search text format are application-wide properties of the active embedding space.

Changing either property creates a different space, and documents must be reindexed before they are searchable there.

A search text format controls how CiteLoom prepares document sections and searches for the selected embedding model.

The document template prepares each searchable document section, and the query template prepares each question or semantic search.

Use the format specified by the embedding model or provider. An incorrect format can reduce search quality even when documents finish processing.

Built-in examples

  • Plain: document {{text}}; query {{text}}.
  • EmbeddingGemma: document title: none | text: {{text}}; query task: search result | query: {{text}}.
  • Snowflake: document {{text}}; use the exact query template required by the selected Snowflake model.

Create a format

  1. Check the embedding model's instructions for document and query prefixes.
  2. Use Copy when a built-in format is a useful starting point, or choose New format to start with plain templates.
  3. Enter a recognizable name that identifies the model or purpose.
  4. Use format version 1 for a new format. Increase it only when saving a changed version of an existing format.
  5. Enter one document template and one query template. Each must contain exactly one {{text}} placeholder.
  6. Save the format, then save the Embedding space settings to select it.
  7. Reindex documents before using semantic search or answers with the new format.

Use Create revision when changing a format that has already been used. CiteLoom keeps the original format so existing indexed documents remain searchable.

Troubleshooting

A document is missing from search: confirm that it shows Ready and is included in your search scope.

Only one source is cited: review Retrieved source material, then ask a comparison question that clearly requires information from each document.

No keyword results appear: enable Include semantic matches or try a synonym.

A semantic result does not contain your search term: semantic search matches meaning, so review the excerpt before using it.

Model services are unavailable: keyword search may still work, but semantic search and answers will remain unavailable.

Accounts and administration

Every user can change their own password under Account and access.

Workspace administrators can add and remove users, assign member or administrator roles, create time-limited setup or password-reset links, and configure providers and features.

System health shows the active runtime, service capacity, and scheduling information. Service readiness checks connectivity and model availability without inference. Optional live tests are selected separately and may use provider credits or local compute.

Error reports contains sanitized operational failures for administrators. Purge logs requires confirmation, removes the retained database error records visible to the workspace, and does not delete Docker or host logs.

Settings resets require confirmation and name whether they affect one value, one feature or panel, or all runtime settings.

Privacy and configured services

CiteLoom sends document and question content to the model and document-conversion services configured for this deployment.

When Docling VLM processing is enabled, each PDF page and the configured instructions are sent from Docling to the selected VLM provider endpoint.

Check Settings and System health to see which services are active and where they run.

Processing stays within your local environment only when every configured service endpoint is also local and trusted.
