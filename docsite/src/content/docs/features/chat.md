title: Chat
description: Ask follow-up questions in a conversation that uses indexed documents.
---

Use Chat when your next question depends on an earlier question or answer.
CiteLoom keeps the conversation and its source evidence together.

## Start a new chat

1. Open **Chat**.
2. Select **New chat**.
3. Enter a chat title.
4. Select **All documents**, **Documents with selected tags**, or **Specific documents**.
5. Select **Review included documents** if you want to check the source list.
6. Select **Create chat**.

![The production New chat form shows a legal document scope with 16 included documents.](/citeloom/images/features/chat-create-legal.png)

## Ask and follow up

1. Check the **Search scope** at the top of the chat.
2. Enter the first question in the message field.
3. Select the send button, or press **Command + Enter** or **Control + Enter**.
4. Review the cited response.
5. Enter a follow-up question in the same message field.

This example uses documents tagged `legal`.
The first question compares the Privacy Act and PIPEDA.
The follow-up question asks about individual access rights.

![The new production legal chat shows cited findings, source files, and the message field.](/citeloom/images/features/chat.png)

## Open another chat

Select **Chat** again to open the recent-chat menu.
You can also press **Command + K** or **Control + K**.
Select the chat that you need.

## Review a response

Each response can show:

- Numbered findings.
- Citations after a statement.
- An **Evidence used in this answer** list.
- An **Open source** link.
- A numbered **Sources** panel on the right.

Select a citation or a source number to inspect its evidence.

## Next action

Open the source evidence for each important response before you use it.
