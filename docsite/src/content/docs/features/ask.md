Use Ask when you need one cited answer to a question.
CiteLoom searches the selected documents and shows the evidence with the answer.

![The production Ask page shows a veterinary question, a verified answer, numbered key points, and six sources.](/citeloom/images/features/ask-veterinary.png)

## Ask a question

1. Open **Ask**.
2. Select **Ask a question**.
3. Select a research thread, or keep **Default (automatic)**.
4. Select **All documents** or **Tags** in **Search scope**.
5. Enter your question in the question field.
6. Select **Ask CiteLoom**.

You can enter a title and select **Create thread** if you want a separate research thread.
The **History** link shows the saved questions in the selected thread.

## Review the answer

The result shows:

- The **Answer status**.
- The answer text.
- Numbered **Key points**.
- The amount of source material that CiteLoom reviewed.
- A numbered **Sources** list.

Select a numbered citation to inspect its source evidence.
Select a source number in the right panel to open the same evidence.
Select **Find sources for this query** if you want search results without another answer.

## Next action

Open each citation that supports an important statement before you use the answer.
