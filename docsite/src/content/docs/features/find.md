Use Find when you need source material and do not need a generated answer.
Find is part of the Ask page.

![The production Find page shows exact and semantic results for a veterinary search.](/citeloom/images/features/find-veterinary.png)

## Find source material

1. Open **Ask**.
2. Select **Find sources**.
3. Select **All ready documents** or **Tags** in **Search scope**.
4. Enter a topic or keywords.
5. Turn on **Semantic matching** if you also want related content.
6. Select **Find sources**.

Find shows exact matches first.
If **Semantic matching** is on, Find also shows related results that use different words.

## Review the results

Each document row can show:

- The file name.
- The number of matches.
- Representative source locations.
- An **Open file** link.
- The top matching excerpts when you expand the row.

Select the check box for each useful document.
Then select **Add to question** to use those documents in Ask.

## Next action

Expand the best result and read the matching excerpt before you add the document to a question.
